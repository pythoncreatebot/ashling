# Ashling

Home page, privacy policy and support pages for the Ashling iOS app, served by GitHub Pages.

- https://pythoncreatebot.github.io/ashling/ (English, with 简体中文 /zh/, 日本語 /ja/, 한국어 /ko/)
- https://pythoncreatebot.github.io/ashling/privacy/
- https://pythoncreatebot.github.io/ashling/support/

## Home page

The four language pages are generated by `tools/build.py` from the text in that file. Edit the
text there, then run:

    python3 tools/build.py

### On launch day

Put the App Store link in `APP_STORE_URL` at the top of `tools/build.py`, run the build, and commit.
The "Coming to the App Store" label becomes a real download button on every language.

### What is in `assets/`

- `site.css`: the one stylesheet. System fonts only.
- `media/jar-day.mp4`: the silent day-to-night loop in the hero (from the first promo video).
- `media/trailer.mp4`: the 19-second trailer, loaded only when someone presses play.
- `shots/<language>/`: the six App Store screenshots, resized to 480 px wide.
- `icon/`: favicon, Apple touch icon and the icon shown on the page.
- `og.png`: the 1200 × 630 picture shown when the link is shared.

There are no analytics, cookies or third-party scripts, to match the app's "no data collected"
privacy label. The only script is first-party: it sends a first-time visitor to their language and
respects the reduced-motion setting for the hero loop.
